# Проверка пилота центра шаблонов документов

Дата: 20.07.2026

Ветка: `fix/main-dashboard-sync`

Коммит реализации: `a4eece8`
Статус решения о production: **НЕ ВКЛЮЧАТЬ до ручной приёмки Preview**

## Что реализовано

- Центр шаблонов в Админке с отдельным редактором, версиями, архивом и откатом.
- Защищённые автополя для клиента, объекта, договора, компании и таблицы сметы.
- Импорт действующего договора ремонта из существующего генератора без ручного переписывания юридического текста.
- Автоматическое сравнение пилотного шаблона с действующим договором перед публикацией.
- Неизменяемые снимки новых документов и отдельные индивидуальные версии.
- Один канонический источник для PDF, Google Docs и Word.
- Безопасный legacy-маршрут: старые документы и все типы вне `repair_fiz` продолжают использовать действующие генераторы.
- Резервное копирование и восстановление новых разделов шаблонов и снимков.
- Feature flag `VITE_DOCUMENT_TEMPLATES_REPAIR_ON=0` по умолчанию.

## Ограничение данных

Новая функциональность пишет только в:

- `titovstroy-document-templates-v1`
- `titovstroy-document-snapshots-v1`
- существующий журнал аудита при ручных действиях с шаблонами

Код не выполняет массовую миграцию и не изменяет существующие объекты, сметы, договоры, доп. соглашения, АВР, финансы, клиентов, подрядчиков или производственные карточки.

- [ ] Визуально сверены PDF-страницы пяти договоров.

## Решение

До выполнения всех пунктов ручной приёмки production-флаг остаётся `0`. После приёмки включение пилота в production требует отдельного подтверждения владельца. Остальные документы (доп. соглашения, дизайн, бронь, подряд, АВР) переносятся отдельными этапами только после успешной проверки договора ремонта.
