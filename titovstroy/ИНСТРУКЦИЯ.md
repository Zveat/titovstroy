# 🏗 TitovStroy — Деплой на Vercel

## Шаг 1 — Настройте Firebase (общая база данных)

1. Откройте https://console.firebase.google.com
2. Нажмите **«Создать проект»** → введите название (например `titovstroy`) → далее
3. В левом меню: **Realtime Database** → **Создать базу данных** → выберите регион **Europe-west1** → режим **«Тест»** (потом настроим правила)
4. В левом меню: **Настройки проекта** (шестерёнка) → **Ваши приложения** → иконка `</>` (Web) → введите название → нажмите **«Зарегистрировать»**
5. Скопируйте объект `firebaseConfig` — он выглядит так:
   ```js
   const firebaseConfig = {
     apiKey: "AIza...",
     authDomain: "titovstroy.firebaseapp.com",
     databaseURL: "https://titovstroy-default-rtdb.europe-west1.firebasedatabase.app",
     projectId: "titovstroy",
     storageBucket: "titovstroy.appspot.com",
     messagingSenderId: "123456789",
     appId: "1:123:web:abc"
   };
   ```
6. Откройте файл `src/App.jsx`, найдите строку `const firebaseConfig = {` и замените значения на ваши

### Правила безопасности Firebase
В Realtime Database → **Правила** вставьте:
```json
{
  "rules": {
    ".read": true,
    ".write": true
  }
}
```
*(достаточно для внутреннего инструмента — доступ по ссылке)*

## Шаг 2 — Загрузите код на GitHub

1. Зайдите на https://github.com → **New repository** → название `titovstroy` → **Private** → Create
2. Установите Git если нет: https://git-scm.com
3. В терминале (папка с проектом):
   ```bash
   git init
   git add .
   git commit -m "first commit"
   git remote add origin https://github.com/ВАШ_ЛОГИН/titovstroy.git
   git push -u origin main
   ```

---

## Шаг 3 — Задеплойте на Vercel

1. Откройте https://vercel.com → войдите через GitHub
2. **New Project** → выберите репозиторий `titovstroy`
3. Framework: **Vite** (определится автоматически)
4. Нажмите **Deploy** → через 1-2 минуты получите ссылку вида `titovstroy.vercel.app`
