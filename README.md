# Репозиторий

Два независимых приложения. Общего кода у них нет.

| Папка | Что это |
|---|---|
| [`titovstroy/`](titovstroy/) | CRM ремонтно-отделочной компании «TitovStroy». React + Vite + Firebase. Память проекта — `titovstroy/CLAUDE.md`. |
| [`gym-os/`](gym-os/) | Personal Gym OS — персональное приложение для силовых тренировок. Next.js PWA, данные на устройстве. См. [`gym-os/README.md`](gym-os/README.md) и [`gym-os/docs/ARCHITECTURE.md`](gym-os/docs/ARCHITECTURE.md). |

Каждое приложение собирается и тестируется из своей папки — у них свои
`package.json` и свои зависимости.
